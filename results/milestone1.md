# Milestone 1: Data and Starter

`python app.py fields` reports these listing fields: `id`, `title`, `description`, `category`, `style_tags`, `size`, `condition`, `price`, `colors`, `brand`, and `platform`.

A wardrobe is a dict with an `items` list. Each wardrobe item has `id`, `name`, `category`, `colors`, `style_tags`, and `notes`. An empty wardrobe has the same shape with no entries: `{"items": []}`.
